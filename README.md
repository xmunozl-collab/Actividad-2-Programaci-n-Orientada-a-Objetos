*Ejercicios de programación orientada a objetos con Java y UML* de Leonardo Bermón Angarita,

## Cómo ejecutar

Cada ejercicio se ejecuta directamente con Python 3. Por ejemplo, para el ejercicio 2.1:

\`\`\`bash
python3 persona.py
\`\`\`

El ejercicio 2.4 está dividido en varios archivos, se ejecuta el de prueba (que importa a los demás):

\`\`\`bash
python3 prueba_figuras.py
\`\`\`
